## 🧑‍💻 About Me

I'm a Computer Science Engineering student (2nd Year) at Jaipur National University, currently exploring different paths in tech and content creation to find where I fit best.

I recently built **ClassHub**, a student dashboard web app with Google Sign-In, attendance tracking, a Safe Bunk Calculator, timetable, and assignment management — built using HTML, CSS, and JavaScript.

Alongside this, I'm learning video editing and graphic design through a mentor-led course (Physics Wallah's editing batch), gaining hands-on experience with professional tools like Adobe Premiere Pro.

I believe in learning by building — trying different things, picking up real skills, and figuring out my path step by step. Open to internships, freelance work, and learning opportunities in web development, editing, or design.
